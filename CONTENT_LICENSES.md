## Publication notes

The artwork in this repository is attributed to the project author by the Git history and is treated as project-authored. If any asset was obtained from another creator or stock library, replace it or add that creator's licence and attribution before redistributing it. The free educational demo does not bundle or cache recitation audio. The application does not send user settings or progress to the hosting server. See [README.md](README.md) for app behavior and privacy details.
